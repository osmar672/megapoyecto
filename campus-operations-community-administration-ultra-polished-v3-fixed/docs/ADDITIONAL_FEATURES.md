# Funcionalidades adicionales

Esta expansión añade módulos independientes a Campus Operations: calendario institucional, biblioteca, reservas de espacios, recursos tecnológicos, documentos, solicitudes administrativas, inventario, directorio, pases de transporte y mesa de ayuda tecnológica.

Cada módulo utiliza datos ficticios, persistencia local idempotente, búsqueda cuando aplica, validación básica, página propia, servicio, fixtures y pruebas. La navegación se registra desde `src/app/features.tsx` sin crear páginas HTML independientes.
