# Contributing

1. Crea una rama `feature/nombre`, `fix/nombre` o `refactor/nombre`.
2. Mantén los cambios enfocados.
3. Ejecuta `npm run ci` antes del Pull Request.
4. No uses `any` salvo una justificación técnica documentada.
5. No introduzcas dependencias sin necesidad.
6. Actualiza tests cuando cambies reglas de negocio.
