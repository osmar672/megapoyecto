# Campus Operations

Aplicación React + TypeScript + Vite para gestión operativa escolar. Esta versión conserva los módulos existentes y agrega diez funcionalidades administrativas independientes.

## Ejecutar

```bash
npm install
npm run dev
```

## Validar

```bash
npm run typecheck
npm test
npm run build
```

## Módulos adicionales

- `/calendar`
- `/library`
- `/room-bookings`
- `/resources`
- `/documents`
- `/requests`
- `/inventory`
- `/directory`
- `/it-support`
- `/transport-pass`

Todos los datos son demostrativos y se almacenan localmente.
