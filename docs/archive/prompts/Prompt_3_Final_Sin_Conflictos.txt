PROMPT 3 — INTEGRACIÓN FINAL, ESTADÍSTICAS Y DOCUMENTACIÓN

CONTRATO CENTRAL DE INTEGRACIÓN — OBLIGATORIO PARA LAS 3 COMPUTADORAS

Este proyecto será desarrollado por separado en tres computadoras y después se unirán los resultados. Por esa razón, la compatibilidad entre módulos es una restricción obligatoria y tiene prioridad sobre cualquier preferencia de organización distinta.

1. ÚNICO ESPACIO GLOBAL PERMITIDO

Todos los scripts deben utilizar exclusivamente este objeto global compartido:

window.SCHOOL_INTRANET = window.SCHOOL_INTRANET || {};

Está PROHIBIDO crear otras variables, constantes o funciones globales propias del proyecto.

Cada etapa debe trabajar dentro de su propio módulo:

- Computadora 1 / Prompt 1: SCHOOL_INTRANET.modules.p1
- Computadora 2 / Prompt 2: SCHOOL_INTRANET.modules.p2
- Computadora 3 / Prompt 3: SCHOOL_INTRANET.modules.p3

Usar un IIFE, closure o estructura equivalente para que let, const, funciones auxiliares, selectores, cache DOM y estado interno queden encapsulados.

Ejemplo de patrón obligatorio:

(function (APP) {
    'use strict';
    APP.modules = APP.modules || {};
    APP.modules.pX = APP.modules.pX || {};
    const MODULE = APP.modules.pX;
    // Todo el código de esta etapa queda dentro de este scope.
})(window.SCHOOL_INTRANET = window.SCHOOL_INTRANET || {});

No declarar en el scope global nombres genéricos como:

- data
- users
- state
- currentUser
- init
- render
- save
- load
- modal
- notifications
- events
- config
- settings

- nombres de animaciones CSS: p1-fade-in, p2-achievement-pop, p3-section-enter
- claves internas de cache o dataset no compartidas

Nunca utilizar IDs genéricos como #modal, #search, #dashboard, #form, #table o #content.
