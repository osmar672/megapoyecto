PROMPT 1 — BASE DE LA INTRANET ESCOLAR

Quiero que desarrolles la primera etapa de una intranet escolar moderna y funcional utilizando únicamente:

- HTML5
- CSS3
- JavaScript
- LocalStorage para almacenar datos temporalmente
- Font Awesome mediante CDN para iconos
- Chart.js solamente si se necesita para algún gráfico

NO utilizar:

- React
- Angular
- Vue
- Node.js
- Frameworks CSS

El proyecto debe organizarse correctamente en archivos como:

- index.html
- styles.css
- app.js

Si consideras necesario dividir JavaScript en varios archivos para organizar mejor el proyecto, puedes hacerlo.

OBJETIVO

Crear la estructura principal de una intranet para un colegio público.

Debe ser una aplicación web moderna, profesional, responsive y fácil de utilizar.

No quiero únicamente diseño visual. Los botones, formularios, filtros, navegación y módulos deben funcionar.

1. LOGIN

Crear una pantalla de inicio de sesión moderna con:

- Logo del colegio
- Correo o identificación
- Contraseña
- Mostrar/ocultar contraseña
- Recordar usuario
- Recuperar contraseña
- Botón Iniciar sesión
- Validaciones
- Mensajes de error
- Loader al iniciar sesión

Agregar animaciones suaves:

- Entrada del formulario
- Animaciones en los campos
- Animación al iniciar sesión correctamente
- Transición desde el login hacia el dashboard

Agregar usuarios de demostración para diferentes roles:

- Administrador
- Docente
- Estudiante
- Familiar

El contenido disponible debe cambiar dependiendo del rol.

2. DASHBOARD

Crear un dashboard moderno con:

- Sidebar
- Header
- Buscador
- Notificaciones
- Avatar
- Nombre del usuario
- Rol
- Tarjetas informativas
- Accesos rápidos

Mostrar:

- Avisos importantes
- Horario del día
- Estado del transporte
- Logros recientes

Agregar animaciones suaves al entrar al dashboard.

3. GESTIÓN DE USUARIOS

El administrador debe poder:

- Crear usuarios

- Eliminar usuarios
- Buscar usuarios
- Filtrar usuarios

- Administrador
- Docente

- Familiar

Cada usuario tendrá:

Guardar los usuarios utilizando LocalStorage.

4. PERFILES

El usuario podrá ver:

- Avatar
- Nombre
- Grado
- Sección
- Intereses
- Actividades
- Logros

Agregar una animación al entrar al perfil.

Agregar buscador para visualizar perfiles de otros estudiantes.

Cuando se seleccione otro estudiante:

- Mostrar su perfil mediante una transición o animación.
- Mostrar solamente información pública.
- Nunca mostrar datos sensibles innecesarios.

5. AVATARES

Crear un sistema sencillo para personalizar el avatar.

Permitir seleccionar:

- Avatar
- Fondo
- Color
- Accesorio

Puede utilizar inicialmente diferentes imágenes o SVG predefinidos.

Guardar la selección con LocalStorage.

Mostrar:

- Viernes

Cada clase debe mostrar:

- Profesor
- Aula

Agregar:

- Vista semanal

Destacar la clase actual según la hora.

7. MÓDULO ACADÉMICO

Crear un módulo académico básico.

El docente puede:

- Registrar calificaciones
- Modificar calificaciones
- Registrar asistencia

El estudiante y familiar pueden:

- Consultar las calificaciones correspondientes
- Consultar asistencia

Los estudiantes NO deben poder modificar calificaciones.

8. CENTRO DE AVISOS

Crear un tablón digital.

Los administradores o docentes autorizados pueden crear:

- Avisos
- Comunicados
- Noticias
- Cambios de horario
- Actividades

Cada aviso tendrá prioridad:

- Normal
- Importante
- Urgente

Los avisos deben aparecer también en el Dashboard.

Si se crea un aviso urgente:

- Mostrarlo destacado.
- Crear automáticamente una notificación.

9. NOTIFICACIONES

Crear un sistema de notificaciones.

Mostrar un icono de campana con contador.

Permitir:

- Ver notificaciones
- Marcar como leídas
- Marcar todas como leídas

Ejemplos:

- Nuevo aviso
- Cambio de horario
- Calificación publicada
- Actividad nueva

10. DATOS COMPARTIDOS

Los módulos NO deben funcionar aisladamente.

Ejemplo:

Si se crea un aviso:

1. Debe guardarse en LocalStorage.
2. Debe aparecer en Avisos.
3. Debe aparecer en Dashboard.
4. Debe generar una notificación.

Si un docente cambia una nota:

1. Debe guardarse.
2. El estudiante debe verla.
3. Debe generarse una notificación.

Centralizar los datos y evitar duplicación innecesaria.

11. DISEÑO

Quiero una apariencia de plataforma educativa moderna.

Utilizar:

- Sidebar
- Cards
- Modales
- Iconos
- Tooltips
- Toasts
- Dropdowns
- Tablas modernas
- Animaciones
- Diseño responsive

NO utilizar emojis como iconos principales.

12. DATOS DE PRUEBA

Agregar datos ficticios suficientes para comprobar el funcionamiento:

- 15 estudiantes
- 5 profesores
- 2 administradores
- Familias
- Horarios completos
- Calificaciones
- Asistencias
- 10 avisos
- Notificaciones

No dejar módulos vacíos.

IMPORTANTE

Esta es la primera etapa del proyecto.

Priorizar:

1. Funcionalidad
2. Organización
3. Navegación
4. Persistencia de datos
5. Diseño
6. Animaciones

Entrégame primero la estructura de archivos.

Después proporciona el código completo de cada archivo.

NO utilices frases como:

"el resto sería similar"

"puedes completar esto"

"agrega aquí..."

Quiero código completo y ejecutable.

No agregues todavía foro, buses, mapa, emergencias, IA ni estadísticas porque se agregarán en la siguiente etapa.
